DualGround-TS

Future-consistent cross-modal integration with behaviorally grounded explanations for event-conditioned time-series prediction

DualGround-TS forecasts what happens next from a time-series history and a textual event. It also verifies that both inputs shape the prediction and that the explanation identifies the evidence the model actually uses.

01 · Why

Two shortcuts can produce a correct forecast for the wrong reason.

Event-conditioned forecasting is a conditional reasoning problem: the event changes the meaning of the recent time-series state, while the state changes how the event should be interpreted. Final accuracy alone cannot tell us whether the model used that interaction.

Problem in the prediction

Shortcut 1: predict from only one modality.

A model may follow the historical trend and ignore the event, or react to event sentiment and ignore the temporal state. Either shortcut can succeed on easy examples without learning the intended cross-modal relationship.

Same event

The event means different things under different historical states.

rate cut → Market ↑
rate cut → Market ↓

So event text alone is insufficient: the model must read the temporal state to interpret the event.

Same history

The same historical state can lead to different futures after different events.

demand rises → Market ↑
supply shock → Market ↓

So trend extrapolation alone is insufficient: the model must use the event to condition the forecast.

Problem in the explanation

Shortcut 2: explain the answer after it has already been produced.

What DualGround-TS must establish

A grounded model must prove two things.

Cross-modal dependenceThe forecast responds to both the historical state and the event.
Behavioral faithfulnessThe cited evidence has a measurable role in the forecast.

02 · How

Build one shared state, then ground it in two complementary ways.

DualGround-TS first extracts task-relevant evidence from the time series and event text, then fuses both sources into a shared state G. The forecast and explanation are decoded from that same state, while two training objectives constrain what information G must preserve.

The main prediction path

Read the two modalities separately; reason about them together.

The temporal readout selects useful history, the event readout selects useful text, and their interaction is represented in G. Using one decoding basis ties the forecast and explanation to the same cross-modal evidence.

Future Grounding

Ground G in the event—not only the trend.

Hold history fixed and swap the event. The real event–history state should align with the realized future more closely than an incompatible one.

same history+real event→G+→closer to future ✓
same history+swapped event→G−→farther from future

Learning rule: matched state closer than mismatched state.

2
Behavioral Grounding

Ground explanations in evidence that controls the forecast.

Intervene on cited evidence: retaining it should preserve the forecast, removing it should change the forecast, and irrelevant context should not.
